## 格式误扣及修正范围

逐一检查 22 封冻结日间附件。它们都在主字段单列有效承诺，并在 `## 说明` 内以“换机时限”介绍该承诺的背景。比如 P01 主字段为七个工作日，说明同时写出通用十日与已获批的七日例外。6 个首批案件因此又被评分器判为必须补发。测试在副本中**只把 22 行的说明标签换成“条款依据”**，保留全部文字、收件人、席位、实际回执和各轮交付不变，分数从 87.3921 升到 96.9750。9.5829 分来自这一格式选择及其后续连带扣分。[逐封复算脚本](replay_notes.py) · [敏感性结果](note-sensitivity.json)

面向后续运行的 3.1 在公开规程中解释字段边界。宿主读取可选 `## 说明` 前的结构化承诺，解释段里的历史说明不再触发补办；缺字段、字段区重复或说明中另列不同的明确时限仍拒绝。自由说明中所有自然语言矛盾尚无法机械穷尽。3.1 的重算副本也保留提交者实际输入，再施加业务变更；旧版使用统一正确前置输入测公式。在本场原件上两种重算方式均通过，改用 3.1 合同所得 96.9750 与改标签敏感性结果相同。剩余 3.025 分具体来自 R4（0.36）、R6（1.54）和 R12（1.125）。正式场保留冻结合同与原分。[3.1 原件复评](revision-replay.json)
