# S4 · 32 与 40 轮早局长度实验

同一席位、同一张 Catan 棋盘，Claude Code + DeepSeek V4.1 Flash 各运行一次。模型在一条连续会话中通过文本工具经营自己的库存，与三个固定策略对手交易，并兑现早先的采购和城市授权。使用框架默认压缩设置。

## 两项延迟交付

| 委托 | 何时给出 | 32 轮组兑现 | 40 轮组兑现 | 客观证据 |
|---|---|---:|---:|---|
| 采购 | 第 1 轮订一张矿石，第 13 轮签字改订一张砖，四张牌的限价继续有效 | 24 | 32 | 清算窗口首笔实际完成的交易。记录收到的货物、数量与付款 |
| 城市 | 第 1 轮授权节点 21，支付后至少留两张小麦 | 32 | 40 | 委任窗口首次实际升级的节点、付款后的余额 |

两种长度从同一初始状态（棋局事件 22）出发。40 轮增加四个完整经营班次，每个班次有开局决策和运营结算两次交互。两组都要交四份库存单。延长期间资源、对手和可选行动都可能变化。若棋局提前自然结束，只复评已发生的事件，缺少行动的决策记为「未观察」。

早局使用同一分制评价两种长度。经营执行满分 100，分为班次 12、库存单 12、完成交易 16、数量与价格 8、备料 18、城市施工 22、小麦预留 12。另列授权正确数／已观察数／计划数。文字复述不计授权分。早局移早了开局位置，也调整了合同与评分，旧版 16／24 轮的经营分单独报告。

## 分项与轨迹证据

| 经营执行 | 32 轮 | 40 轮 |
|---|---:|---:|
| 完成班次 | 12/12 | 12/12 |
| 库存单准确 | 12/12 | 12/12 |
| 完成采购 | 16/16 | 16/16 |
| 数量与价格 | 8/8 | 8/8 |
| 委任前备料 | 4.5/18 | 4.5/18 |
| 委任窗口内建城 | 0/22 | 0/22 |
| 小麦预留 | 10/12 | 10/12 |

两场各完整运行一次，均完成全部用户轮次。32／40 轮累计输入加输出分别为 **8,207,396／15,758,901 tokens**。按供应商记录计入重复发给模型的历史，缓存命中已含在输入中。两场分别有 115／163 条桌面工具回执，全部可在后续模型请求中核对。供应商失败 0 次，引擎分别拒绝 1／2 次操作，原始回执均保留。

- **采购正确。** 第 13 轮两场都复述了修订，到第 24／32 轮仍用四张木材换得一张砖（事件 263／394）。模型实际使用了距离兑现 11／19 轮的采购信息。
- **节点记对，授权时间用错。** 第 15 轮两场看到合法建城动作后，就把节点 21 升成了城市（事件 150／156）。它们把游戏允许施工解释为委任已经打开，并把建城费用当作小麦预留的例外。两场付完只剩 0／1 张麦。正式委任时节点已经升级过，无法在该节点再次施工。按冻结评分，城市为窗口内未观察，建设 0/22；审计把提前兑现另列。两场在委任前只备有三张麦、零矿石，备料均为 4.5/18。
- **40 轮触发一次默认原生压缩。** 32 轮峰值 114,613，无压缩。40 轮进入委任前峰值 149,353，也无压缩。第 40 轮执行中，第 196 次请求生成摘要，第 197 次真实请求逐字采用其摘要正文，供应商输入从 167,717 降至 6,816。Claude 原生边界记录 167,225 → 5,367，两处计量口径不同。[实际采用的摘要](adopted-summary.txt)
- **摘要保留了规则和一个错误的执行判断。** 摘要同时记有节点 21、采购修订、两麦预留，却把事件 156 概括为守住了小麦底线，实际余额为 1。压缩后模型又发起两次矿石报价并铺路，末轮称委任仍开放且节点 21 还需要升级；引擎显示节点早已是城市，两回合窗口已经用完。压缩前的第 15 轮总结已给提前施工和预留豁免找了理由。这里能测到摘要如何保留错误，现有证据无法将原始施工失误归因于压缩。

**长度判断。** 40 轮足以在本场自然跨过边界，并留下 8 次采用压缩后上下文的请求；两场经营分和两项授权表现相同。32 轮可作较低成本对照。要检验压缩对交付的影响，可在未来版本的后段预设一项独立、仍可执行的不可逆订单，在固定轮次用先前签发的参数交付。所有模型共享同一日程，按实测是否跨过压缩分别报告。单模型每组一场，且 40 轮增加了四个真实班次，当前不足以判定长度的因果效应、稳定触发率或跨模型区分度。

**复核。** 两条参考路径均在 Docker 完成两项授权及 100/100 经营分。21 项 S4 测试通过。两次模型轨迹从公开包独立解压重放，评分文件逐字节一致，实验机 253 + 334 个文件通过校验。

## 离线复评

从仓库根目录运行。每个目录中的 manifest 标明实际执行版本。原始供应商报文和 Claude 事件保存在实验机，公开包包含题面、桌面动作、回执和局面指纹。

```sh
(cd rollout/s4 && shasum -a 256 -c SHA256SUMS)
run=$(mktemp -d)
tar -xzf rollout/s4/early-duration-20261128-replay.tar.gz -C "$run"
docker build -t longworkmem-catan:early-league tasks/s4
for group in rounds-32 rounds-40; do
  python -m tasks.s4.early_league "$run/$group" --replay --image longworkmem-catan:early-league
done
```
