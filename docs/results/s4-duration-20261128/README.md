# S4 正式节点与交互长度对照

正式 S4 采用原默认节点 21。两项授权分别是改批后的东线支路和首段获批的城市。参与者只看到工作委托和游戏工具。早期节点 46 留在历史档案中，供复核既有结论。

## 两项独立读数

**授权应用**逐项记录当前有效目标、首次相关行动和正确／错误／未观察。报告同时给出计划决策数和实际可观察数。例如没有建城，缺少用于判断城市授权应用的行动证据。

**经营执行**满分 100。主干 8、购砖报价 4、买砖到账 12、建设勘定支路 8、相应定居点交付 18、资本准备 18、城市建设与补救 20、库存预留 12。建设错误城市但在规定窗口支付材料并完成升级，可获得相应的执行分，授权项单独记错。没有合成的记忆总分。

小麦预留有六个固定窗口，各 2 分。实际推进且没有违规，包括主动节麦，均可得分。没有动作、只写自述或仅重复查看初始棋盘均为 0 分。已完成交付的最终现场核查可以构成有效收尾。所有主动用麦后的越线逐笔保留，并报告窗口最低支出后余量。无主动支出的最低值记为空。强制弃牌、被抢以及已提交但未成交的报价不会被记作支出。

| 窗口 | 可核验进度 |
|---|---|
| 动工至收货 | 完成主干或确认购砖 |
| 支路与定居点 | 铺成勘定支路或交付定居点 |
| 移交与补给 | 真实掷骰、材料交易或施工 |
| 生产与营运资金 | 同上 |
| 决策记录至城市委任 | 同上 |
| 保全、补救和最终验收 | 同上；已完成交付后可以使用终局核查 |

在冻结的上批原始轨迹上，节点 21 的旧综合分为 68，新口径为授权 2/2、执行 82/100。预留得 6/12，事件 239、314、389、391 均已登记。节点 46 的历史对照为授权 2/2、执行 100/100。两套分数的定义不同。[历史复算及违规明细](historical-rescore.json)

## 16 轮和 24 轮怎么比

两种长度使用同一节点、棋局、骰序起点、模型、对手、目标、四份班末库存表和评分器。16 轮将开局、运营和登记合在一个委托中；24 轮把四个班次各拆为三个委托，开局和运营共用同一个实际回合额度，登记时棋盘只读。库存登记单列验证。第 1 轮的城市授权分别在第 13 轮和第 21 轮要求兑现。模型可以自行记笔记或在阶段总结中重述决定。

同一参考策略在两种长度的所有共同阶段结束时产生相同的棋局指纹，两次均授权 2/2、执行 100/100，四份库存表全部准确。走错城市的参考对照为授权 1/2、执行 100/100。[程序对照](controls.json)

另跑一场同样的 24 轮题面，将 Claude Code 的自动压缩阈值设置为 20%。该设置只在独立诊断场启用。按原生事件核实压缩发生的轮次及其与授权兑现的先后关系。[Claude Code 自动压缩设置](https://code.claude.com/docs/en/env-vars)

## 默认长度对照结果

Claude Code + DeepSeek V4.1 Flash 在两场均完成四份准确交割表。16 轮在第 13 段正确升级 21，运营窗口发生一次越线，执行 98。24 轮在第 21 段也升级 21，施工窗口发生一次越线；资本截止时有两张矿石，执行 92。授权两场均为 2/2。两场实际动作不同，模型累计推进的普通回合分别为 6 和 7，程序参考路径验证两种分段本身没有多给行动机会。

默认 16 轮在委任前有 75 次模型请求、累计输入 2,310,100、单次输入峰值 62,027。24 轮对应为 73 次、2,358,661 和 63,074。两场均没有原生压缩。虽然用户首次交代节点到启用的轮次差从 12 增到 20，模型在第 12 段和第 20 段各自主复述过节点 21，紧接着便进入委任。模型在持续维护授权；新增八次用户交互没有形成八段全新的实质作业。

**正式版采用 16 轮，24 轮保留为长度实验。** 两个长度各一次且共用一个节点、一张地图和一个模型。这次能验证任务沿袭和成本变化，跨模型区分度和同模型稳定性仍需其他证据。

## 提前压缩诊断

第三场沿用 24 轮及节点 21。Claude Code 在第 9、19 轮各出现一次原生 auto 压缩，均早于第 21 轮城市委任。实际供应商输入先从 36,686 降到 4,849 tokens，第二次从 37,571 降到 4,155。第 38 和第 74 个真实请求都含有 Claude Code 采用的前序摘要。摘要加入工作单中没有的木材和砖预留，后续总结复述了这条错误要求。

模型在委任时仍说出正确城市节点，手中持有 4 麦和 3 矿。当前是 Ash 的普通回合，但引擎正等待本席执行强制弃牌。模型认为列出的弃牌只能由 Ash 执行，一直没有推进到城市建设。授权应用为路线正确、城市未观察，经营执行 68。缺少城市操作证据，无法把未交付诊断为忘记城市节点。单场提前压缩中同时观察到摘要失真和界面理解失误，对执行差异的因果贡献尚无法量化。
