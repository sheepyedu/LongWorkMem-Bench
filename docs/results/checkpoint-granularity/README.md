# 增加检查点能否减少分数跳变？

本试验在全部 24 场已冻结作答上先复现原分，再仅替换选定的评分项。业务题面、模型作答、评分时点的原始文件、各业务大项权重和满分均保持可比。试验没有发起新的模型调用。旧 C1 的预算终止和提前签收仍按旧口径保留。下文的候选分不替换正式成绩。

## 两种不同的改法

**新增时间检查点**要能发现原来没有观察到的状态，例如切去做别的事期间，已提交文件是否仍可调阅。**细化已有时点的评分项**要把可以独立核对的成果分开，例如“谁授权”“如何处置”“金额是否正确”。所有子项共享原来的分值。同一事实重复出现十次，不会自动变成十份独立证据。

| 目标 | 本次试验的评分约定 |
|---|---|
| W1 的 20 分预留结果 | 四个办理日各 4 分，同一业务案的 25% 给正确项目、岗位和授权，25% 给前述均正确且决定和目标金额正确，50% 给整案连同本期增减额全部正确。重复案不获分，额外案进入分母；用错授权，该案仍为零。另 4 分仍按三份旧报件等权分。R3 报件增加 R4 留存、R5 报件增加 R6 留存，各与 R9 最终留存对分；R8 之后只有 R9，保留原分。 |
| C1 的 R5 撤令处置和 R7 三个截止日的处置清单 | 每项保留 50% 给整表正确，25% 按业务 ID 正确覆盖率，25% 专门核查只改变早期签发人就会翻转的 ID。ID 必须有唯一且正确的决定；缺行、重复决定不得相应分，额外 ID 进入分母。缺文件、无效表形为零。其余快照、余额、入账与新来件执行检查保留原分。签收和轮末仍各自计分。 |
| S1 的 70 分执行结果 | A：在每队原有的器材配套、实际送达两对字段中，整对正确得满，单字段正确得该对的 1/4，无有效行得零。B：发现 A 会奖励抄过期仓单后追加的对照，在整对未完成时只给“相对旧仓单发生了变化且填对”的字段部分分。两者均保留全对满分。30 分登记、十区等权和各班权重不变；登记格式等价另做开关。 |

各分项的严格基线从同一份交付重新计算。C1 用同一种子的另一签发人作为反事实答案，只在宿主离线使用。W1 的 R9 增减额继续以参评者当时真实提交的 R8 目标额为前值。选择拆分位置用到了上一轮错误审计；B 又参考了本次负对照结果，整个试验属于样本内分析。

## 结果

表内为“均分 / 四场极差”。S1 在这张表中对新旧两列均保留原登记解析，以隔离字段细分的影响。S1 候选列采用 B。

| 题目 | 模型 | 原分 | 候选分 |
|---|---|---:|---:|
| W1 | DeepSeek | 50.10 / 41.00 | 50.10 / 41.00 |
| W1 | Qwen | 35.28 / 32.30 | 35.56 / 33.41 |
| C1 | DeepSeek | 43.42 / 20.04 | 43.76 / 18.66 |
| C1 | Qwen | 31.95 / 25.78 | 32.31 / 25.78 |
| S1 | DeepSeek | 58.28 / 29.13 | 60.72 / 29.79 |
| S1 | Qwen | 86.46 / 15.76 | 87.80 / 14.09 |

**W1** 只有 Qwen 17219 的 R9 增减额链取得部分分：36 案的授权与处置金额均正确，但只有 16 案的增减额也正确；总分增加 1.1111。它原本就是该组最高场，所以极差略有增大。八场在新增中间时点与最终时点的留存判定均相同。受控反例中，把正确参考交付的 R3 文件仅从 R4 快照移除、R9 恢复，原分仍为 100，新分为 99.3333。可以保留这个诊断来区分“中途丢失后恢复”和“持续留存”，本批没有证据表明它能普遍降低方差。

**C1** 两个实例发生变化。DeepSeek 17219/B 的 R7 第九日处置清单原为 0/3；94.03% 的业务 ID 和 90.96% 的签发人敏感 ID 得到了唯一正确决定，候选给 1.3874/3。另做单错注入：从同实例 720 行正确清单出发，仅将 177 个签发敏感 ID 中的一行换成另一签发口径的决定。旧规则损失 3.00 分，新规则损失 1.5053 分（均为该面板内分数）。完整清单和新来件复跑仍可失败。该场轮末分由 87.00 升至 91.13，历史综合分由 35.60 升至 36.98；Qwen 17231/A 综合分由 35.60 升至 37.01。预算终止的 Qwen 17217/A 仍为 14.15。只取双方走完的三对且只看轮末，原均分双方同为 95.67，新均分为 97.04、97.08。更细的部分分能说明“错了多少”，也会进一步暴露轮末天花板。

**S1** 的格式与字段评分应分开看：

| 同一批原始答案，均分 / 极差 | DeepSeek | Qwen |
|---|---:|---:|
| 原规则 | 58.28 / 29.13 | 86.46 / 15.76 |
| 仅修正登记等价格式 | 64.92 / 2.98 | 86.46 / 15.76 |
| 仅普通部分分 A | 65.07 / 28.55 | 89.19 / 12.48 |
| 格式修正 + A | 71.71 / 2.02 | 89.19 / 12.48 |
| 格式修正 + 变更字段部分分 B | 67.35 / 4.01 | 87.80 / 14.09 |

四个种子中，无视公文、仅抄旧仓单且不登记的对照，均分由 **16.50 升至 26.92**（A），B 保持 **16.50**。四个种子的空提交均为零，参考解均为 100。B 的两模型均分仍相差约 20.45 分，但 DeepSeek 极差比“仅格式修正”大。降低极差不是选 A 的充分理由。

## 采用建议与边界

建议优先并列给出 C1 的业务覆盖率、历史敏感覆盖率和整表正确性；W1 的切换后留存可作诊断，S1 的 B 可作下一批候选。正式计分前先固定规则，用未参与此次设计的任务实例及同题独立重复检验。四个不同种子的极差、标准差均是跨实例描述量。减少一个局部悬崖不保证总分极差下降，更不能由这 24 场推断同一模型重复执行的方差。

- [24 场逐场分数](scores.csv)中的 granular 是三题第一种细分（S1 为 A）；s1_changed_field 是 B，带 format 的列同时接受等价登记格式。
- [六组均值、极差与样本标准差](summary.csv)可区分“极端两场更接近”和“所有四场波动缩小”。
- [分项复算记录](components.json)列出 W1 分日命中、C1 两个签收面板和历史敏感覆盖、S1 各班得分。[正、负对照](controls.json)提供参考、缺失和过期仓单对照值。
- 复现时使用 Python 3.12、原始批次目录、W1 的宿主 LibreOffice 和能读取 C1 冻结运行卷的 Docker。根目录执行 `python -m scripts.checkpoint_trial BATCH OUTPUT`。BATCH 含原批次的 status/ 和已展开的三题运行目录。评分器先核对 24 个正式分，再输出实验 scores.csv、summary.csv、components.json。
