## 新版任务增加的两项责任

- **跟踪八份保障合同。** 第2日签章表决定受益对象、来源案与“接续/独立”，次日原件归还。第7日起仅以单号流转，办理须连到该场第3日真实实占；停兑有签发日和生效日。旧券为2席、新保障为3席时，接续兑现3席，独立义务兑现5席。更晚生效的停兑不能改变早期已知计划或其他客户的待遇。允许保留合法笔记。
- **接手并验证实际工作簿。** 上班模型在一个站沿用“只能全额满足”的历史公式，空模板与继承文件都可用。宿主在副本中分别设置零容量、充足容量和“先满足第一人后只剩一席”，检查各案分配、候补和未受影响的站。错误公式能通过零容量与充足容量两项，部分满足探针能定位它。输入数值与计算结果分别核验。
