## 对题目难度的判断

本场证明公开材料足以支持跨期办理。模型用可持久化笔记保留了借阅合同，并能查账、重算和补办。它几乎满分有业务依据。累计输入含跨请求重复读取，单场也没有观察到压缩后恢复。此前的 88.8361 是旧作答换权回放，不能当成同一新版的第二次试跑。本场无法估计模型内方差或模型间差距。[离线策略和旧作答回放](../)

下一题可先在固定实例上做一项离线检验：只改一条早期合同关系或撤销生效日，让精确办理和“记错这条规则”的办理各走一次真实柜面，比较哪些客户在截止日获得不同结果。让关键约束确实改变席位或对客承诺，再确定评分分量。J02 表明，如果正确与错误参数都会得到相同席位，继续细拆表格分也很难提高主指标的区分度。
