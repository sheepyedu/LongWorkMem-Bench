## 分差归因

- **单桌保留。** 第 229 个事件用两张羊走海贸换一砖，留下零张羊，无法同时支付定居点的四种资源。结束回合后 Flint 在第 233 个事件抢占节点 6。补救时做了两笔海贸，但无法恢复授权点。
- **单桌改线。** 铺到节点 52 后缺砖，模型把手牌付不起时的动作列表当成节点不可达，在尚可向其他席报价时结束了回合。补救阶段有待处理的他席报价，模型未推进到自己的回合。
- **切桌保留。** B 桌没有砖，模型看到当前只能结束回合，便认为永远铺不了路，未尝试报价。固定局面的程序参考解能购砖、铺路并结束回合。回到 A 桌后，模型正确铺西线，三次报价都没完成可支付的组合。结束回合后 Flint 在第 245 个事件占节点 6，补救建在未授权的节点 50。
- **切桌改线。** 在 B 桌给 Ash 两张麦购砖并铺路。切回后，模型一度把 B 桌的 Ash 道路状态带进 A 桌解释，最终依据 A 桌现场铺对东线。交付先用两羊换砖，再用两麦换羊，建设前正好剩两麦，建设后只剩一麦。第六段自述仍说预留已满足，评分按真实手牌扣分。

预设的稳妥路径在两条历史均可达满分。铺完主干和支路后，从 Sail 用一羊加一麦换一砖，建成授权点仍剩两张麦。相同牌局、牌面和报价下，原策略的 Ash、Sail 都接受。提高 Ash 谨慎度后，Ash 拒绝卖最后一砖，Sail 仍接受。这个程序对照验证了对手策略变化的实际作用，可以独立于切桌来评估。

## 解释边界

**当前数据支持保留加难后的多阶段主桌作业；切桌适合继续作为诊断条件。** 已经观察到跨桌状态混淆和自述与实盘不符，但没有观察到首条支路得分下降。切桌组均分 16，单桌均分 15，差异由同一个完成定居点却违反储备的案例产生。两次切桌只有一次完成了 B 的全部操作，两条历史共用同一棋盘。中段处理 A 的状态确认和完整 B 交易的交互量也不同。这些条件不足以估计纯切换的效应、记忆效果的稳定性或不同模型的区分度。

下一轮适合固定 B 的必做操作与完成口径，增加等长度的 A 桌只读对照，重复多个配对局面，并增加「不同桌对同资源的规则相反」的实例。若目标包含压缩后的恢复，应延迟授权使用至更长的任务链，并实际观测压缩。当前六段只验证短程中断和续作。
