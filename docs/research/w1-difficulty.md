# W1 采购与薪酬进阶题 · 配对校准

## 运行方案

旧版保留为级别 0，历史 Docker 复验中的 DeepSeek A、B 都是 100 分。新题使用同一套九轮办公工具，增加两档采购、工时和资金交接规则。五个采购委托合计 40 分，财务批准和奖金 35 分，邮件送审及执行 25 分。计分依据是阶段快照、实际重算和邮箱事件。

开发种子 431。两个模型在相同难度、种子、人事变体、镜像、Claude Code 和每会话 350 次上游请求上限下运行。先观察一级，再比较二级。校准目标是 DeepSeek 平均 30–70 分，配对平均分比千问高约 8 个百分点，本次用 5–11 个百分点作为观察区间。成绩表示 100 分制上的部分得分。每对先相减再取平均，调用失败或运行中断单列。

事先保留种子 1733 和 2671，各用 A、B 两种早期人事批复。同一版的公开文件与提示要在两个模型间逐轮核对摘要。确定候选题面和计分规则后再使用这四个验证实例。报告逐对分数、各业务阶段得分和方向一致性；四对的结果仅支持本批样本的描述。
