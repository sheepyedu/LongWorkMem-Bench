# W1 · 跨月采购关账与奖金分配

## 九轮如何接续

| 轮次 | 用户委托与应交成果 | 后续依赖 | 过程分 |
|---|---|---|---:|
| 1 | 接手跨库采购。关联采购、收货和发票，交初版底表、待认领及寄售逐单清单。 | 留存凭证迁移通知和主管口头签发的六组预留岗位与额度。 | 3 |
| 2 | 接收六月替换页、退回及认领材料，更新关账版；按当日工单发首询并留真实回执。 | 这一版成为六月实际报送基准；同批人事邮件规定 E07 从 7 月 16 日起转岗。 | 4 |
| 3 | 冻结上轮实际报送的底表、待认领和寄售原表；凭证移库前保存人事索引，办理 6 月 30 日预留。 | 七月售后和工资分别需要六月原凭证、当时有效的工牌和合同。 | 3 |
| 4 | 管理层临时开会。用六月报送版制作差异简报和优先跟进清单。 | 会后签发有期限的临时代办，变更范围仅覆盖指定项目与争议类型。 | 3 |
| 5 | 回到采购账，按 7 月 8 日截点更新当前账，解释跨期变化，办理售后冲抵、续核函和当日预留。 | 六月定版仍须可调阅；续核使用当日有效岗位和此前实际询证记录。 | 4 |
| 6 | 按书面会签交付可结项目及额度，待签项目继续挂起；完成银行核验。 | 一个库区撤回代办，另有一家供应商仅在 8 月 4 日停办，两项范围分别生效。 | 3 |
| 7 | 按早期人事批复、合同和双签调班单折算工时，交工资明细、待核票据、调班表及可重算工资簿。 | 项目池、个人金额和归属都要正确；财务改工时或池额后仍须自动重算。 | 3 |
| 8 | 核对已付和在途垫款，按岗位分别拟送审稿并办理 8 月 4 日预留。 | 每份实际草稿及当天实报的预留金额成为次日办理依据。 | 4 |
| 9 | 按早班回单重算可付余额，逐包执行获准的投递、留置或重拟，登记实际回执并归档。 | 8 月 5 日停办到期，逐案按昨天真正提交的金额补提或冲回。 | 3 |

## 怎样评分

九个过程点共 **30 分**，按当轮交付和可验证操作取证。四项业务结果共 **70 分**，每项内部按完成比例给部分分。

| 业务结果 | 满分 | 宿主取证 |
|---|---:|---|
| 采购关账 | 18 | 核对六月报送、七月当前账、寄售认领和售后冲抵，并检查六月定版能否持续调阅。 |
| 工资结算 | 20 | 联合核对员工、项目、工时和实发金额，检查项目总额，并用 Calc 在独立副本上实际改工时、改池额。 |
| 资金交接 | 12 | 对照两个银行截点、书面授权、实际收件人及附件范围，核验真实处置。 |
| 跨期预留 | 20 | 四个办理日各核对 36 案的项目、岗位、批文、处置、预留额和变动额，并检查历史申报留存。 |

例如，遗漏第四轮会议简报，只损失该轮的 3 分。第八轮少报的金额会影响当天成绩；如果第九轮根据真实少报数正确追调，仍可取得相应信用。宿主可用 `--details` 查看每个评分点的证据。

## 运行与复评

需要 Claude Code、Python 3.12、Docker，以及可供宿主复算工作簿的 LibreOffice。独立 Docker VM 须将运行目录设在可写共享挂载中。DeepSeek 读取宿主 ARK_API_KEY，千问沿用适配器的 DEEPSEEK_BASE_URL 与 DEEPSEEK_API_KEY。

```sh
docker build -t longworkmem-office:1 -f tasks/w1/Office.Dockerfile .
python -m tasks.w1.pilot runs/w1/example --backend docker --level 8
python -m tasks.w1.advanced runs/w1/example --details
python -m tasks.w1.review runs/w1/example
python -m unittest discover -s tasks/w1/tests -t . -v
W1_TEST_DOCKER=1 python -m unittest tasks.w1.tests.test_docker -v
```

千问运行时另加 `--model qwen3.8-flash`。独立 VM 的集成测试使用共享路径环境变量 W1_TEST_ROOT。逐轮冻结实际文件和邮件副本。九个过程点合计 30 分，采购、工资、资金交接及预留四项结果合计 70 分。每个检查点以其原子证据的完成比例计分。见上方九轮交付表。

工资簿复评要求 LibreOffice 成功完成所有已生成的变更用例。进程退出异常、超时或缺少转换文件时会提示复评；可在恢复 Calc 后重放同一份冻结交付。

公开实例为 17217/A，每轮可以继续查阅和执行。历史 ERP 批数窗口可用 `--erp-window` 显式复现，`--limit N` 仅供成本控制；两者均记录为实验条件。
